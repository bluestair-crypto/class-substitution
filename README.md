# 결보강 추천

교사 주간시간표와 결보강 일지를 사용자의 브라우저에서 직접 읽어, 결강 시간에 적합한 보강 교사를 순위별로 추천하는 정적 웹앱입니다.

## 사용 방법

1. **교사 주간시간표** Excel 파일을 선택합니다. `주간시간표` 시트를 우선 사용하며, 병합된 요일 헤더와 교시를 자동 인식합니다.
2. **결보강 일지** Excel 파일을 선택합니다. 선택 날짜의 월 시트가 자동 선택되며 필요하면 기준 시트를 바꿀 수 있습니다.
3. 날짜와 해당 요일에 존재하는 교시를 선택하고 **보강 교사 찾기**를 누릅니다.
4. 1~5순위에서 **배정**을 누르면 현재 탭의 임시 누계가 증가합니다. 오늘 배정 기록에서 개별 취소하거나 전체 초기화할 수 있습니다.

지원 형식은 `.xlsx`, `.xls`입니다. 시간표에는 `교사` 열과 다음 행의 교시 헤더가, 일지에는 같은 행에 성명(`성명`, `교사`, `교사명`, `이름`)과 `누계` 열이 있어야 합니다.

## 추천 알고리즘

해당 교시가 공강이며 결보강 순번표에 있는 교사 중, 표기 시수가 정확히 `18`인 교사, 보강 후 3교시 연속 수업이 생기는 교사, 보강 후 하루 5시간 이상이 되는 교사를 제외합니다. 남은 후보를 **현재 보강 누계 오름차순**, 동률이면 **결보강 일지의 원래 행 순서**로 정렬합니다. 제외 목록에서는 적용된 모든 사유를 확인할 수 있습니다.

## 개인정보 보호 구조

- 앱은 백엔드, 데이터베이스, 분석 서비스가 없는 정적 웹앱입니다.
- 파일은 브라우저의 File API로 읽고 JavaScript 메모리 안에서만 처리합니다. 서버나 외부 API로 파일 및 내용을 전송하지 않습니다.
- 교사명, 시간표, 결보강 기록을 소스에 포함하거나 `localStorage` 등에 저장하지 않습니다.
- 원본 Excel을 수정하지 않습니다. 새로고침하거나 탭을 닫으면 불러온 정보와 배정 기록은 사라집니다.

## 개발 및 테스트

```bash
npm install
npm run dev
npm test
npm run build
```

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**에서 GitHub Actions 또는 정적 배포 브랜치를 선택합니다.
2. `npm ci && npm run build`를 실행하고 생성된 `dist/` 폴더를 Pages에 배포합니다.
3. 프로젝트 경로로 배포한다면 Vite의 `base` 옵션을 저장소 이름에 맞추거나, 빌드 시 `vite build --base=/저장소명/`을 사용합니다.

저장소에는 실제 학교 Excel 파일이나 실제 교사 정보를 커밋하지 마세요.
